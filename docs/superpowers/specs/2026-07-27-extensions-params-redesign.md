# 扩展管理 & 参数预设页面重设计 — 设计规格

> **日期**：2026-07-27  
> **状态**：已确认  
> **视觉参考**：`temp_extparampreview/index.html`

---

## 1. 背景

工具栏图标化与 API 设置页面已改造为轻量卡片式 + Lucide 图标 + 全 CSS 变量。扩展管理（`ExtensionManager.vue`）和参数预设（`ParamPresetSelector.vue`）仍使用硬编码颜色、border-radius 不一致（6px）、opacity 不统一（0.3/0.4/0.55）、focus 色非 accent。

## 2. 目标

将两个页面统一为卡片式布局，CSS 变量化，引入 Lucide 图标，与 API 设置页面视觉语言一致。

---

## 3. 扩展管理页面

### 3.1 布局

```
┌──────────────────────────────────────────┐
│ ⚡ 扩展管理                 [安装扩展] [管理扩展] │  标题栏
├──────────────────────────────────────────┤
│ ┌──────────────────────────────────────┐ │
│ │ dashboard  v1.0.0  GIT               │ │  扩展项（默认）
│ │ 内置仪表盘扩展                        │ │
│ │ ID: dashboard          [详情]         │ │
│ └──────────────────────────────────────┘ │
│ ┌──────────────────────────────────────┐ │
│ │ my-plugin  v0.2.1  ZIP    · 已禁用   │ │  扩展项（禁用）
│ │ 自定义翻译插件                        │ │
│ │ ID: my-plugin           [详情]         │ │
│ └──────────────────────────────────────┘ │
└──────────────────────────────────────────┘
```

### 3.2 安装 Modal

点击"安装扩展"弹出 Modal，分三区：

```
┌─────────────────────────────┐
│ 安装扩展                  ✕  │
├─────────────────────────────┤
│ GIT 仓库地址                  │
│ [https://github.com/...]    │
│ 分支（可选）                  │
│ [main_______________]       │
│─────────────────────────────│
│ ZIP 文件路径                  │
│ [选择 .zip 文件...] [浏览]    │
├─────────────────────────────┤
│                    [安装]    │
└─────────────────────────────┘
```

- Git 地址：`input-mono` 等宽字体
- ZIP 路径 + 浏览按钮：浏览打开系统文件管理器
- 安装按钮右对齐

### 3.3 管理 Modal

点击"管理扩展"弹出 Modal，列出所有扩展及其管理控件：

```
┌──────────────────────────────────────┐
│ 管理扩展                           ✕  │
├──────────────────────────────────────┤
│ dashboard  v1.0.0  GIT                │
│ [✓ 已启用]  [更新🟢] [卸载]            │  有更新时显示更新按钮+绿点
│──────────────────────────────────────│
│ my-plugin  v0.2.1  ZIP               │
│ [  已禁用]            [卸载]           │  ZIP无更新按钮
└──────────────────────────────────────┘
```

**更新按钮显隐规则**：
- Git 来源 + 远程有新版本 → 显示"更新"按钮，右上角绿色圆点（`7px`）指示
- Git 来源 + 无新版本 → 隐藏更新按钮
- ZIP 来源 → 从不显示更新按钮

> 注：版本检测需要后端支持（`git ls-remote` 比对），如暂时无法实现则所有 Git 扩展默认显示更新按钮。

### 3.4 扩展项卡片规格

| 属性 | 值 |
|------|-----|
| 背景 | `var(--bg-input)` = `#fafbfc` |
| 边框 | `1px solid var(--border-light)` |
| 圆角 | `var(--radius-md)` = `10px` |
| 禁用态 | `opacity: 0.45` |
| 间距 | `margin-bottom: 8px` |

### 3.5 来源标签

```
GIT  /  ZIP
```

- `font-size: 10px`, `text-transform: uppercase`
- `color: var(--text-muted)`, `background: var(--bg-tertiary)`
- `border-radius: 4px`, `padding: 1px 6px`

### 3.6 UI 元素映射

| 原元素 | 新样式 |
|--------|--------|
| 安装按钮（两个） | 合并为"安装扩展" accent 按钮（+ 图标） |
| 管理按钮（新增） | outline 按钮（齿轮图标），打开管理 Modal |
| 启用/禁用 | 自定义 toggle-box（`18×18`, `border-radius: 4px`，与 API 设置统一） |
| 更新按钮 | 条件显示，outline-blue，有更新时绿点角标 |
| 卸载按钮 | outline-red |
| 详情按钮 | outline（默认模式唯一可见的操作按钮） |

## 4. 参数预设页面

### 4.1 布局

```
┌──────────────────────────────────┐
│ ⚙ 参数预设                        │
│──────────────────────────────────│
│ [下拉▾] [+] [🗑]                  │  预设选择行
│──────────────────────────────────│
│ TEMPERATURE                      │
│ [0.7________________________]    │
│ MAX TOKENS                       │
│ [4096_______________________]    │
│ TOP P                            │
│ [1.0________________________]    │
│──────────────────────────────────│
│ [💾 保存]                         │  紧凑按钮
└──────────────────────────────────┘
```

### 4.2 卡片规格

整体包装为一张 `.card`（与 API 设置一致）：
- 背景 `var(--bg-primary)`, 边框 `var(--border)`, 圆角 `var(--radius-lg)=16px`, 阴影 `var(--shadow-sm)`
- Header 使用 `<SlidersHorizontal>` Lucide 图标 + "参数预设" label
- 内部间距 `16px`

### 4.3 表单控件

| 元素 | 样式 |
|------|------|
| 预设下拉 | `flex:1; padding:7px 10px; border:1px solid var(--border-light); border-radius:var(--radius-sm); bg:var(--bg-input)` |
| 新建/删除按钮 | `32×32px` 图标按钮，同 API 设置 PresetSelector |
| focus | `border-color: var(--accent)` + `box-shadow: var(--focus-ring)` |
| 标签 | `11px uppercase, var(--text-muted)` |
| disabled | `opacity: 0.45` |

### 4.4 保存按钮

紧凑 `inline-flex`，`padding: 8px 18px`，accent 色背景 + 💾 图标，与测试按钮风格一致。
